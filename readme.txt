wiseCampaign integrates seamlessly with standard WooCommerce hooks, popular WordPress themes (Astra, OceanWP, GeneratePress, Storefront), and modern page builders.

== Installation ==

= From Your WordPress Dashboard =
1. Go to **Plugins > Add New**.
2. Search for **wiseCampaign**.
3. Click on the **Install Now** button.
4. Click **Activate** after installation completes.

= Manual Installation =
1. Download **[wiseCampaign](https://downloads.wordpress.org/plugin/wisecampaign.zip)**.
2. Upload the `wisecampaign` folder to the `/wp-content/plugins/` directory.
3. Activate **wiseCampaign** from your WordPress Plugins page.

== Usage Instructions ==

1. Go to **WiseCampaign -> Settings**, toggle the status to Active to enable the banner, and select a template from the list of views. Click **Save**.
2. Go to **Appearance -> Customize -> wiseCampaign** to adjust colors, typography, timers, and layout settings.

== Frequently Asked Questions ==

= Q. Who should use wiseCampaign? =
A. Any WooCommerce store owner looking to boost conversion rates, run scheduled flash sales, reduce cart abandonment, and add social proof.

= Q. What are the requirements to use wiseCampaign? =
A. You need WordPress 5.4+ and WooCommerce active on your website. PHP 7.4 or higher is required.

= Q. Can I choose where the Banner will appear? =
A. Yes. You can target campaigns sitewide, restrict them to specific products/pages, or target devices (desktop or mobile).

= Q. What features are included in the free version? =
A. The free version includes wiseBanner, StockBar, Direct Checkout, Sales Notifications, and wiseCart.

= Q. What extra features are available in the Pro version? =
A. Pro unlocks the WooCommerce Dynamic Discount Manager (BOGO, bulk pricing, tiered discounts, spend-based rules), advanced targeting filters, premium pre-built templates, and deeper styling controls.

= Q. Will wiseCampaign slow down my site? =
A. No. wiseCampaign is performance-optimized and utilizes modular asset loading with scoped CSS resets to keep page load times fast.

= Q. Do I need coding knowledge to use this plugin? =
A. None at all. Everything is managed through an intuitive WordPress dashboard and visual settings.
